<table>
<tr>
<td width="62%" valign="top">LYMORA — Local network. Real connection.

An offline-first Windows LAN messenger designed for people working on the same local network. No internet connection is required for messaging.

What I'm engineering:
- Interface: Electron + React + TypeScript; three-column chat UI, themes, rich interactions.
- Networking: Go-based peer discovery, direct and group messaging, file transfers.
- Reliability: Message states, retries, local history, recovery, and offline behavior.
- Security: Cryptographic identities, TLS transport, explicit pairing, and careful trust handling.
- Product experience: Next.js showcase, GSAP/Motion animations, Cloudflare Pages deployment.
Stack: React TypeScript Electron Go Next.js Cloudflare
