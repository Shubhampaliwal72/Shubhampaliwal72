- Desktop experience: Electron + React + TypeScript, with a premium three-column chat interface, themes, and thoughtful interactions.
- Local networking: Go-based discovery, direct messaging, group conversations, and file transfers.
- Reliability and security: Device identities, encrypted LAN transport, pairing, recovery, and careful handling of message history.
- Product website: Next.js marketing experience with motion-driven storytelling and deployment on Cloudflare Pages.
